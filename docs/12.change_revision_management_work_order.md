# 계약·실행예산 차수 관리 작업지시서

## 목적

계약금액 또는 세부 실행예산이 변경되어도 증감액만 별도로 입력하지 않는다. 관리자가 계약관리 전체금액을 새 차수로 작성한 뒤, 세부 실행예산은 이전 차수를 복사하지 않고 새 예산본으로 처음부터 전체 작성한다. 차수별 내용은 비교 화면에서만 확인한다.

## 작성 흐름

1. 관리자만 계약관리에서 새 변경 차수를 시작하고 계약 공종별 견적·계약금액과 목표이익률을 작성한다.
2. 계약 저장 후 담당자는 해당 차수의 세부 실행예산을 빈 예산본부터 전체 작성한다. 신규 공종과 신규 실행항목을 추가할 수 있다.
3. 계약과 세부 실행예산 전체 작성이 완료되면 해당 차수의 실행예산 전체 결재를 요청한다.
4. 대표 승인 시 해당 차수가 현재 계약·실행예산 승인본이 된다.
5. 해당 차수의 전체 실행예산 항목을 기준으로 업체 비교견적과 발주품의를 다시 진행한다. 기존 승인 발주는 자동 변경하지 않는다.
6. 기존 승인 원본은 수정하지 않으며, 새 차수와 원본은 비교표에서만 함께 표시한다.

## 데이터 규칙

- 차수는 프로젝트별로 1차 승인본 다음의 2차, 3차 순으로 부여한다.
- 새 차수는 계약 스냅샷과 빈 세부 실행예산 스냅샷을 각각 저장한다.
- 스냅샷을 저장할 때 현재 프로젝트의 계약·실행예산 원본 테이블을 덮어쓰지 않는다.
- 비교는 직전 승인본 스냅샷과 현재 작성 중인 차수의 전체 금액을 나란히 표시한다.
- 차수 결재는 해당 차수의 세부 실행예산 전체를 대상으로 하며, 승인 시 현재 금액과 표시 차수를 반영한다.

## 화면 규칙

- 계약관리 전체 입력폼을 먼저 제공한다.
- 계약 저장 후 빈 세부 실행예산 전체 입력폼을 제공한다.
- 증감액 입력란, 변경 범위 체크박스, 공종별 자동 배분 기능은 제공하지 않는다.
