# 📋 [작업명세서] 준공정산 및 공사 완료 마감 기능 개발

## 1. 개요 및 목적
* **목적**: 공사 완공 후 프로젝트의 **계약/매출, 실행예산, 발주, 기성 및 실제 지급 데이터**를 통합 집계하여 최종 손익(원가, 이익, 이익률)을 산출하고, 미지급/미정산 항목을 확인한 뒤 프로젝트를 최종 마감(정산완료) 처리함.
* **주요 원칙**:
  1. **전단계 데이터 자동 연동 (Auto Aggregation)**: 계약, 실행예산, 발주, 기성/지급 모듈에서 등록 및 승인된 데이터를 자동 집계하여 보여주며, 수동 재입력을 최소화함.
  2. **손익 자동 계산**: 
     * $\text{최종 계약금액(매출)} = \text{최초 계약금액} + \text{계약 변경금액}$
     * $\text{최종 실행예산} = \text{최초 실행예산} + \text{실행예산 변경금액}$
     * $\text{최종 발주금액} = \text{최초 발주금액} + \text{발주 변경금액}$
     * $\text{최종 원가} = \text{실제 지급누계 (또는 최종 발주금액/승인 기성 기준 산출)}$
     * $\text{최종 이익} = \text{최종 계약금액} - \text{최종 원가}$
     * $\text{최종 이익률(\%)} = \left( \frac{\text{최종 이익}}{\text{최종 계약금액}} \right) \times 100$
  3. **마감 제어 (Settlement Gatekeeper)**: 미지급금액 및 미정산 항목이 잔존하는 경우 정산완료 처리를 차단하거나 경고(Warning)를 발생시킴.

## 3. 백엔드 (Backend) 비즈니스 로직 및 제어 규칙

### 3.1 정산완료 처리 제어 규칙 (Validation Rules)
1. **미지급/미정산 검증**:
   * $\text{미지급금액} > 0$ 인 경우: 
     * **경고 팝업 호출**: *"미지급 잔액이 남아있습니다. 정산을 계속 진행하시겠습니까?"*
     * 정산완료 시 사유 입력 필수화 또는 회계담당자 특별 승인 권한 부여.
2. **프로젝트 상태 변경**:
   * 정산 완료 승인 시 프로젝트 상태(`project_status`)가 `IN_PROGRESS` $\rightarrow$ `COMPLETED_SETTLED` (준공정산 완료)로 변경.
   * 정산 완료 후에는 추가 발주(PO), 실행예산 변경, 기성 청구 등록이 **차단(Lock)**됨.

## 4. 데이터베이스 설계 (SQLite DDL)

```sql
-- 프로젝트 준공정산 마감 정보 테이블
CREATE TABLE IF NOT EXISTS project_settlements (
    settlement_id TEXT PRIMARY KEY,               -- 정산 ID (예: STL-2026-001)
    project_id TEXT UNIQUE NOT NULL,              -- 프로젝트 ID
    
    -- 계약/매출 스냅샷
    initial_contract_amount REAL NOT NULL,        -- 최초 계약금액
    change_contract_amount REAL DEFAULT 0,        -- 계약 변경금액
    final_contract_amount REAL NOT NULL,          -- 최종 계약금액
    
    -- 실행예산 스냅샷
    initial_budget_amount REAL NOT NULL,          -- 최초 실행예산
    change_budget_amount REAL DEFAULT 0,          -- 실행예산 변경금액
    final_budget_amount REAL NOT NULL,            -- 최종 실행예산
    
    -- 발주 스냅샷
    initial_po_amount REAL NOT NULL,              -- 최초 발주금액
    change_po_amount REAL DEFAULT 0,              -- 발주 변경금액
    final_po_amount REAL NOT NULL,                -- 최종 발주금액
    
    -- 기성 및 지급 스냅샷
    approved_claims_total REAL NOT NULL,          -- 승인 기성누계
    actual_paid_total REAL NOT NULL,              -- 실제 지급누계
    unpaid_balance REAL NOT NULL,                 -- 미지급금액
    uncollected_receivable REAL DEFAULT 0,        -- 미수금 (직접 입력)
    
    -- 최종 손익
    final_cost REAL NOT NULL,                     -- 최종 원가
    final_profit REAL NOT NULL,                   -- 최종 이익
    profit_margin_rate REAL NOT NULL,             -- 최종 이익률 (%)
    
    -- 정산 상태 및 관리
    settlement_status TEXT DEFAULT 'DRAFT',       -- DRAFT(작성중), REQUESTED(승인요청), SETTLED(정산완료)
    settlement_notes TEXT,                        -- 정산 비고 및 미지급 사유
    settled_by TEXT,                              -- 정산 처리자 ID
    settled_at DATETIME,                          -- 정산 완료 일시
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE
);
```
