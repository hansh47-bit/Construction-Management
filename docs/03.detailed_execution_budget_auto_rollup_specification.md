# 📋 \[작업명세서\] 세부실행예산 입력 및 실행예산 자동 집계·연동 시스템 개발

## 1. 개요 및 구조

* **목적**: 직원이 공종/실행항목별로 세부 내역(외주비, 폐기물, 인건비, 장비비, 운반비 등)을 작성하면, 동일한 `실행항목ID`(예: `EX-001`)를 기준으로 **상위 실행예산 금액이 자동으로 합산(Roll-up)되어 반영되는 시스템**을 구축함.

* **핵심 계층 구조**:
  $$
  \text{프로젝트} \longrightarrow \text{상위 실행예산 항목 (EX-001 등)} \xrightarrow{\text{1:N 자동 합산}} \text{하위 세부실행예산 항목}
  $$

* **자동 집계 원칙**:
  $$\text{상위 실행항목(EX-001)의 실행예산} = \sum (\text{동일 EX-001 식별자를 가진 세부실행예산 금액})$$
  $$\text{세부실행예산 금액} = \text{수량} \times \text{단가}$$

## 2. 프론트엔드 (Frontend) 작업명세서

### 2.1 UI 구성 및 입력 필드 (첨부 이미지 규격 반영)

1. **상단 요약 정보 카드 (Summary Header)**
   * **프로젝트 코드/명**: `P-2025-001` (선택된 프로젝트)
   * **계약 공급가액 및 목표원가한도**: 실시간 표시
   * **세부실행예산 총 합계**: 전체 세부 산출 내역의 금액 합계 실시간 반영
   * **결재 상태 및 제어 버튼**: `작성중`, `결재대기`, `승인완료`, `반려`

2. **세부실행예산 입력 Grid (Detail Sheet Table)**
   * **컬럼 규격**:
     1. `프로젝트` (Project Code, 예: `P-2025-001`) - 자동 할당
     2. `실행항목ID` (Execution Item ID, 예: `EX-001`, `EX-002`) - 선택/자동연동
     3. `공종` (Category, 예: 인테리어공사, 전기·통신공사, 사인공사, 냉난방공사)
     4. `실행항목` (Execution Item Name, 예: 철거/폐기물, 목공사, 도장/필름, 가구/집기, 현장경비/직영)
     5. `원가구분` (Cost Type, 드롭다운: `외주비`, `폐기물`, `인건비`, `장비비`, `운반비`, `자재비`, `현장경비` 등)
     6. `업체/내용` (Vendor / Description, 예: 철거업체 견적, 혼합폐기물 반출, 보양·현장정리 등)
     7. `규격/단위` (Unit, 예: `식`, `대`, `인`, `m2` 등)
     8. `수량` (Quantity, 숫자)
     9. `단가` (Unit Price, 숫자)
    10. `금액` (Amount, $\text{수량} \times \text{단가}$ 자동 계산)
    11. `증빙링크` (Evidence Link / URL)
    12. `비고` (Note, 예: 예시, 입력 등)

3. **실행예산 요약 뷰 (Auto-Calculated Parent View)**
   * 세부실행예산 입력 시 하단 또는 탭 영역에서 `실행항목ID`별 집계 현황을 실시간 확인:
     * **EX-001 (철거/폐기물)**: `6,020,000` 원 ($3,500,000 + 1,800,000 + 720,000 + 0 + 0$)
     * **EX-002 (목공사)**: `0` 원
     * **EX-008 (현장경비/직영)**: `0` 원

### 2.2 UX 및 데이터 처리 요구사항
* **자동 계산 & 즉시 합산**:
  * `수량` 또는 `단가` 수정 시 해당 행의 `금액`이 즉시 재계산됨.
  * 동일 `실행항목ID` 그룹의 총액이 상위 실행예산 집계 테이블에 즉시 업데이트됨.
* **행 추가/복사 기능**: 동일한 `실행항목ID`(예: `EX-001`)에 대해 세부 항목 행을 계속 추가/확장할 수 있는 기능 제공.

## 3. 백엔드 (Backend) 작업명세서

### 3.1 세부-상위 자동 집계 비즈니스 로직

1. **상위 실행예산 금액 자동 갱신 트리거 (Trigger / Service Logic)**:
   * 세부 항목 추가/수정/삭제 발생 시, 서버는 아래 쿼리를 수행하여 상위 실행예산 마스터 금액을 자동 반영함.
     ```sql
     UPDATE project_execution_budget_items
     SET budget_amount = (
         SELECT COALESCE(SUM(amount), 0)
         FROM project_execution_budget_details
         WHERE project_execution_budget_details.budget_item_id = project_execution_budget_items.item_id
     )
     WHERE project_id = :project_id;
     ```

2. **목표원가한도 검증**:
   * $\sum (\text{모든 세부 항목 금액}) > \text{목표원가한도}$ 일 경우, 알림 깃발(`over_target_limit: true`) 응답 데이터 전달.

## 4. 데이터베이스 설계 (SQLite / DDL Script)

```sql
-- 1. 상위 실행예산 항목 테이블 (집계 대상)
CREATE TABLE IF NOT EXISTS project_execution_budget_items (
    item_id TEXT PRIMARY KEY,                 -- 실행항목ID (예: EX-001, EX-002)
    project_id TEXT NOT NULL,                 -- 프로젝트 코드 (예: P-2025-001)
    category_name TEXT NOT NULL,              -- 공종 (인테리어공사 등)
    item_name TEXT NOT NULL,                  -- 실행항목 (철거/폐기물 등)
    budget_amount REAL DEFAULT 0,             -- 세부 항목들의 합계 (자동집계)
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE
);

-- 2. 세부실행예산 상세 항목 테이블 (이미지 서식 100% 일치)
CREATE TABLE IF NOT EXISTS project_execution_budget_details (
    detail_id TEXT PRIMARY KEY,               -- 세부항목 고유 ID
    project_id TEXT NOT NULL,                 -- 프로젝트 코드 (예: P-2025-001)
    budget_item_id TEXT NOT NULL,             -- 실행항목ID (예: EX-001, EX-002)
    category_name TEXT NOT NULL,              -- 공종
    item_name TEXT NOT NULL,                  -- 실행항목
    cost_type TEXT NOT NULL,                  -- 원가구분 (외주비, 폐기물, 인건비, 장비비 등)
    vendor_description TEXT,                  -- 업체/내용
    unit TEXT,                                -- 규격/단위 (식, 대, 인 등)
    quantity REAL DEFAULT 0,                  -- 수량
    unit_price REAL DEFAULT 0,                -- 단가
    amount REAL GENERATED ALWAYS AS (quantity * unit_price) STORED, -- 금액 (자동 계산)
    evidence_link TEXT,                       -- 증빙링크
    note TEXT,                                -- 비고 (예시, 입력 등)
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE,
    FOREIGN KEY (budget_item_id) REFERENCES project_execution_budget_items(item_id) ON DELETE CASCADE
);
```
