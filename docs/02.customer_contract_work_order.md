# 📋 [작업지시서] 고객 견적·계약 관리 및 목표원가한도 시스템 개발

## 1. 개요 및 목적
* **목적**: 프로젝트별(프로젝트 코드/명) 고객 제출 견적 및 최종 계약금액을 공종별로 등록·관리하고, 공급가액 기준으로 목표이익률에 따른 **목표원가한도**를 자동 산출하여 실행예산 작성의 기준선(Baseline)으로 활용함.
* **주요 원칙**:
  * **프로젝트 식별자 연동**: 모든 계약 및 공종 데이터는 `project_id` 및 `project_code`에 매핑.
  * **공급가액 중심 손익 계산**: VAT(부가가치세)는 별도 관리하며, 손익 및 목표원가 계산은 **공급가액** 기준으로 처리.
  * **목표원가한도 자동 계산**: $\text{목표원가한도} = \text{계약 공급가액} \times (1 - \text{목표이익률})$.

## 2. 프론트엔드 (Frontend) 작업지시서

### 2.1 UI/UX 구성
1. **프로젝트 선택 및 기본 정보 상단 영역**
   * **프로젝트 헤더**: 프로젝트 코드(예: `P-2026-001`), 프로젝트명(예: `성가수녀원 리뉴얼공사`), 발주처/고객명 표기
   * **목표이익률 설정 카드**:
     * 입력 필드: 목표이익률 [%] (예: `45.0%`)
     * 실시간 표시: 계약 총 공급가액, **목표원가한도** (자동 계산되어 강조 표시)

2. **공종별 견적 / 계약 금액 입력 및 관리 테이블 (Grid)**
   * **입력/조회 컬럼**:
     1. `공종` (드롭다운/직접입력: 인테리어, 전기, 사인, 냉난방, 철거 등)
     2. `견적 제출 공급가액` (원)
     3. `최종 계약 공급가액` (원)
     4. `VAT (10%)` (자동계산 / 직접수정 가능)
     5. `VAT 포함 총액` (공급가액 + VAT 자동계산)
     6. `비고`
   * **행 추가/삭제**: 공종별 행 추가/삭제 기능 제공
   * **하단 합계 행 (Total Row)**:
     * 계약 공급가액 합계, VAT 합계, VAT 포함 총액 합계 실시간 집계

3. **견적/계약 증빙 파일 첨부 영역**
   * 제출 견적서(PDF/Excel), 최종 계약서 스캔본 등록 및 다운로드 기능

### 2.2 사용자 경험(UX) 요구사항
* **실시간 계산 반응성**: 공종별 공급가액을 수정하거나 목표이익률을 변경할 때 상단의 **계약 총 공급가액** 및 **목표원가한도**가 즉시 갱신되어야 함.
* **단위 표시**: 천 단위 쉼표(`,`) 자동 적용 및 원화(`원`) 단위 자동 포맷팅.

## 3. 백엔드 (Backend) 작업지시서

### 3.1 비즈니스 로직 및 자동 계산 규칙
1. **VAT 및 총액 자동 계산**:
   * $\text{VAT} = \text{계약 공급가액} \times 0.1$
   * $\text{VAT 포함금액} = \text{계약 공급가액} + \text{VAT}$
2. **계약 총 공급가액 집계**:
   * $\text{계약 총 공급가액} = \sum (\text{공종별 최종 계약 공급가액})$
3. **목표원가한도 자동 계산**:
   * $\text{목표원가한도} = \text{계약 총 공급가액} \times \left(1 - \frac{\text{목표이익률(\%)}}{100}\right)$
   * *예시*: 계약 공급가액 `198,790,207원`, 목표이익률 `45%`일 때
     $$\text{목표원가한도} = 198,790,207 \times (1 - 0.45) = 109,334,614\text{원}$$

## 4. 데이터베이스 설계 (SQLite / DDL Script)

```sql
-- 1. 프로젝트 테이블 (목표이익률 및 계약 총액 집계 컬럼 포함)
CREATE TABLE IF NOT EXISTS projects (
    project_id TEXT PRIMARY KEY,
    project_code TEXT UNIQUE NOT NULL,
    project_name TEXT NOT NULL,
    target_profit_rate REAL DEFAULT 0.0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2. 공종별 고객 계약 상세 테이블
CREATE TABLE IF NOT EXISTS customer_contract_items (
    item_id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    work_category TEXT NOT NULL,               -- 공종명 (인테리어, 전기, 사인 등)
    quoted_amount REAL DEFAULT 0,              -- 견적 제출 공급가액
    contract_amount REAL DEFAULT 0,            -- 최종 계약 공급가액
    vat_amount REAL DEFAULT 0,                 -- VAT (10%)
    total_amount REAL DEFAULT 0,               -- VAT 포함 금액
    note TEXT,                                 -- 비고
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE
);

-- 3. 계약 관련 첨부파일 테이블
CREATE TABLE IF NOT EXISTS contract_files (
    file_id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    file_name TEXT NOT NULL,
    file_path TEXT NOT NULL,
    file_type TEXT,                            -- ESTIMATE, CONTRACT 등
    uploaded_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE
);
```
